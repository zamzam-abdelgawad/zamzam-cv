# Zamzam Abdelgawad - Portfolio Website

A modern, responsive portfolio website showcasing my experience as a Frontend Developer with 2+ years of experience in building scalable web and mobile applications.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with gradient header and organized sections
- **Easy to Update**: Simple HTML structure makes it easy to update content
- **Fast Loading**: Lightweight single-page design with no external dependencies
- **Professional Layout**: Well-organized sections for experience, projects, skills, and education

## 📋 Sections

- **Header**: Name, title, and contact information in a two-column layout
- **Summary**: Brief professional overview
- **Experience**: Detailed work history with project descriptions
- **Education**: Academic background
- **Internships**: Training and bootcamp experience
- **Skills**: Visual grid of technical skills
- **Projects**: Portfolio of completed projects with tech stacks

## 🚀 Getting Started

### Prerequisites

No prerequisites needed! This is a simple HTML file that runs in any modern web browser.

### Installation

1. Clone this repository:
```bash
git clone https://github.com/zamzam-abdelgawad/portfolio.git
```

2. Navigate to the project folder:
```bash
cd portfolio
```

3. Open `index.html` in your web browser:
```bash
open index.html
```
or simply double-click the file.

## 🎨 Customization

### Changing Colors

The main color scheme uses blue (`#0066cc`). To change it:

1. Find the color code `#0066cc` in the `<style>` section
2. Replace it with your preferred color
3. Update the gradient in the header section if desired

### Adding/Removing Sections

Each section is wrapped in `<section>` tags. You can:
- Add new sections by copying the structure
- Remove sections by deleting the corresponding `<section>` block
- Reorder sections by moving the `<section>` blocks

### Updating Content

- **Contact Info**: Update in the header section
- **Experience**: Add new jobs in the Experience section
- **Projects**: Add new projects in the Projects section
- **Skills**: Add or remove skill badges in the Skills section

## 🌐 Deployment

You can deploy this portfolio on various platforms:

### GitHub Pages
1. Push your code to GitHub
2. Go to repository Settings → Pages
3. Select branch and save
4. Your site will be live at `https://yourusername.github.io/portfolio`

### Netlify
1. Drag and drop the folder to Netlify
2. Your site will be live instantly

### Vercel
1. Import your GitHub repository
2. Deploy with one click
